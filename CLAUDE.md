# robohand

Дипломная работа: проприоцептивная обратная связь по разрежению для замкнутого
цикла вакуумного захвата. Dobot Magician E6 + DOBOT ES01 + Nuwa HP60C.

**Начинать с [docs/STATUS.md](docs/STATUS.md)** — там текущее состояние,
измеренные результаты, блокеры и порядок работ. Замысел и научная рамка —
[docs/research_design.html](docs/research_design.html).

Общение на русском.

## Характер работы

Это **исследование**, а не разработка: кафедра требует защитить тему как одну
из двух. Стенд — средство измерения, результат — числа и границы применимости.
Предложения оценивать вопросом «какую гипотезу это проверяет». Отрицательный
результат тоже публикуется.

## Запуск

Скрипты запускать **через обёртки `.sh`**, не `python tools/.../xxx.py`: VS Code
подмешивает snap-переменные, которые ломают Qt-бэкенд OpenCV. Общая чистка
окружения живёт в `tools/_lib/env.sh`, профили `plain` / `ros` / `qt`.

`tools/` разложен по функциям:

```bash
# камера
tools/camera/start.sh          # драйвер HP60C, останавливать ТОЛЬКО Ctrl+C
tools/camera/reset.sh          # сброс USB, лечит мёртвую область
tools/camera/zone_check.sh     # что попадает в рабочий круг (--save = эталон)
tools/camera/depth_check.sh    # гейт по глубине
tools/camera/plan.sh           # таблица «дистанция → пятно/маркер/зона»
tools/camera/rgbd.sh           # просмотр RGB-D, клик меряет расстояние

# рука
tools/arm/check.sh             # связь, режим, поза. Ничего не двигает
tools/arm/clear_fault.sh       # снять аварию, коды расшифровываются по-русски
tools/arm/gripper.sh           # присоска on / off / состояние
tools/arm/find_es01.sh         # перебор выходов в поисках линии захвата
tools/arm/first_motion.sh      # РУКА ПОЕДЕТ, только при человеке у стопа
tools/arm/park.sh              # РУКА ПОЕДЕТ: парковка и обесточивание

# калибровка камера-рука
tools/calib/capture.sh         # съёмка поз, РУКА СТАНОВИТСЯ ПОДАТЛИВОЙ
tools/calib/solve.sh           # решение AX=XB по снятому набору
tools/calib/check.sh           # сквозная проверка: пиксель → координаты руки

# измерения
tools/measure/pick_normal.sh   # тычок → нормаль; --approach ДВИГАЕТ РУКУ
tools/measure/normal_error.sh  # ошибка нормали по кадру, главный измеритель RQ2
```

`tools/calib/capture.sh` перед съёмкой сам поднимает камеру с чистого листа и
снимает аварию с руки — оба отказа молчаливые, и наткнуться на любой посреди
серии значит потерять все позы. Отключается флагом `--skip-preflight`.

Окружение: `.venv` с `--system-site-packages` (иначе не видны `rclpy` и
`cv_bridge`). **Не ставить `opencv-python` в venv** — затенит системный
cv2 4.6.0, против которого собран `cv_bridge`, и камера отвалится.

## Железо: цифры, которые ломают наивные предположения

- **ES01: 55 кПа, 2.0 л/мин** — слабее, чем закладывал исходный план (≥10 л/мин).
  Это делает сигнал уплотнения контрастнее, но замедляет фронт.
- **Досягаемость руки — главное ограничение зоны.** При инструменте вниз и
  z=120 достижимо y от -205 до -455, x ±200. Камеру целить в СЕРЕДИНУ этой
  полосы (y около -340), иначе она смотрит туда, куда рука не дотянется.
  Проверять `arm.reachable(pose)` (InverseKin) ДО движения, а не после аварии.
- **Чашка 35 мм**, не 15-20. Нормаль оценивается на этом масштабе.
- **Длина инструмента 70 мм** (`TOOL_LENGTH_MM`) от фланца до губы чашки.
  Ошибка здесь — промах по высоте при подводе. Перепроверить штангенциркулем.
- **Минимум глубины 0.2 м считается до ближайшей точки сцены**, не до стола.
  Ближе — кадр приходит целиком нулевым, без ошибок в лог.
- **Имена окон OpenCV только латиницей** — с кириллицей Qt не находит окно и
  `setMouseCallback` падает молча, клики не доходят.
- **`cv2` системный 4.6.0** — старое aruco-API (`CharucoBoard_create`,
  `interpolateCornersCharuco`). `CharucoDetector` из 4.7+ отсутствует.
- **Чёрные поверхности не измеряются** — ИК поглощается. ChArUco-доска годится
  только для RGB (hand-eye), для работы с глубиной нужен матовый однотонный лист.
- **ES01 включается `ToolDOInstant(1, 1)`** — выход на фланце, не на клеммнике
  контроллера. Работает при обесточенных суставах, `EnableRobot` не нужен.
- **`GetAngle`/`GetPose` не годятся для измерений** — отдают уставку, а не
  энкодер. Для метрологии только `q_actual` из потока 30004, шум 0.033°.
- **ES01 кафедральный**: резать и вскрывать нельзя, любые врезки — проходные.
- **Ориентация фланца — RPY `Rz(rz)·Ry(ry)·Rx(rx)`**, определено перебором.
- **Присоска как крепление пружинит**: отклонение растёт с наклоном руки,
  корреляция +0.92. Для hand-eye нужен механический упор, не только вакуум.
- **Робот на 192.168.5.1** (LAN1), профиль NM `robohand-arm`. До первого
  `RequestControl()` отвечает `Control Mode Is Not Tcp` на всё, включая чтение.
- **HP60C поднимается с мёртвой областью**, если драйвер перезапущен поверх не
  отпущенного устройства: до 17 % рабочего круга приходит нулями всегда, без
  ошибок в лог. Стабильна в пределах сессии. Лечится `run_reset_camera.sh`.
  **Любой сбор данных начинать с `run_zone_check.sh`** — отказ молчаливый.
- **Ошибка оценки нормали (RQ2): median 2.93°, p95 7.19°** на 1107 точках
  плоского стола; за порог 5° выходит 14 %. `tools/measure/normal_error.sh`.
- **Радиальная выгнутость глубины НЕ ВОСПРОИЗВЕЛАСЬ.** Записанные ранее −19 мм
  на краю при повторе дали <1 мм, и периферия по нормалям не хуже центра.
  Ограничение зоны r<180 px пока оставлено, но под вопросом — нужен третий
  замер на контрольной плоскости.

## Желательное

| Компонент | Зачем |
|---|---|
| Вакуумметр стрелочный | Независимая проверка калибровки датчика — в статью нужна |
| Виброразвязка под насос (пенка/сайлентблоки) | Риск §9: вибрация портит повторяемость |
| Ресивер 50–100 мл (шприц/банка) в линии | Сглаживает пульсации мембранного насоса. **Внимание:** ставить ПОСЛЕ датчика, иначе смажет переходный процесс, ради которого всё делается |
| USB-Ethernet адаптер | На ноуте нет RJ45 (проверено: только wlp1s0). Для LAN-подключения к E6 нужен адаптер, иначе только Wi-Fi 192.168.1.6 |
| Печать переходника под фланец E6 | `hardware/cad/`. Размеры фланца — из мануала E6 |

## Схема линии

```
насос ──► клапан 3/2 ──► тройник ──► трубка вдоль руки ──► присоска
                            │
                            └──► XGZP6847D (I2C → Arduino → USB → ПК)
```

Датчик — **между клапаном и чашкой**, максимально близко к чашке по объёму линии.
Чем больше паразитного объёма между датчиком и чашкой, тем сильнее размазывается
фронт нарастания разрежения — а скорость этого фронта и есть главный признак для RQ1.

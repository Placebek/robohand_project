# RoboHand Teach & Repeat — Windows

GUI для Dobot Magician E6 + вакуумной присоски ES01. Позволяет подключиться к роботу, включить ручное ведение, физически переместить руку, сохранять именованные суставные позы, сохранять/открывать JSON и воспроизводить точки.

## Важно
- Этот пакет пока не является подтверждённо протестированным на физическом E6. Проверяйте сначала связь и чтение состояния.
- Нужен Windows 10/11, Python 3.10–3.12 (64-bit), Git for Windows, сеть до контроллера и поддерживаемая версия Dobot TCP/IP Python SDK V4.
- SDK скачивается официальным репозиторием Dobot. Если SDK не поддерживает вашу конфигурацию Windows, GUI не сможет подключиться без адаптации SDK.
- По умолчанию IP `192.168.5.1`; измените его в окне под фактическую сетевую конфигурацию.
- Сначала запускайте без предмета, на малой скорости, с доступным штатным аварийным стопом.
- Не запускайте обратный порядок точек с предметом. Это диагностический тест траектории, а не автоматический сценарий возврата предмета.
- Функция Stop отправляет программную команду остановки; она не заменяет аппаратный аварийный стоп.

## Установка и запуск
1. Распакуйте обновлённый архив обратно в корень репозитория `robohand_project-master`.
2. Установите Python 3.10–3.12 x64 и Git for Windows.
3. Запустите `windows_app\setup_windows.bat`.
4. Запустите `windows_app\run_gui.bat`.
5. Введите IP контроллера и нажмите «Подключиться».
6. Проверьте показания суставов/TCP. Только после этого пробуйте включение суставов и ручное ведение.

## Сборка EXE
На Windows после успешной установки запустите `windows_app\build_exe.bat`. Исполняемый файл будет в `dist\RoboHandTeachRepeat\RoboHandTeachRepeat.exe`. Скопируйте всю папку `RoboHandTeachRepeat`, не только EXE.

## Обучение
1. Подключиться.
2. Включить питание суставов, соблюдая меры безопасности.
3. Начать ручное ведение (руку поддерживать — она может просесть).
4. Физически переместить руку в безопасную точку и нажать «Сохранить текущую позу».
5. Для событий захвата нажать «Вакуум ВКЛ + записать событие» или «Вакуум ВЫКЛ + записать событие» в нужной позе.
6. Завершить ручное ведение, сохранить JSON.
7. Проверить список точек. Первый тест воспроизведения выполнять без предмета.

## Ограничения текущей версии
- Записываются именованные позы, а не непрерывная высокочастотная траектория.
- Программа воспроизводит суставные точки. Между точками траектория и столкновения не моделируются.
- Проверка достижимости по обратной кинематике не доказывает отсутствие столкновений.
- Успех захвата не подтверждается датчиком давления; команды вакуума лишь включают/выключают ToolDO1.
- «Обратный порядок точек» — тест без предмета; для безопасного обратного pick-and-place нужен отдельный сценарий с точками захвата/подхода/отхода и событиями вакуума.

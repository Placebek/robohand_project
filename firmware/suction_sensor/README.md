# Прошивка сенсорной приставки (конфигурация с DOBOT ES01)

Arduino ничем не управляет — присоску включает робот. Arduino только меряет
давление и ловит фронт команды.

## Распиновка (Arduino Nano)

| Пин | Куда |
|---|---|
| A4 (SDA) | XGZP6847D SDA (+ подтяжка 4.7 кОм на VCC) |
| A5 (SCL) | XGZP6847D SCL (+ подтяжка 4.7 кОм на VCC) |
| 5V, GND | питание датчика |
| D2 (INT0) | коллектор PC817, эмиттер на GND Arduino |

Оптопара: линия DO робота (24 В) → резистор 2.2 кОм → анод PC817, катод на
0 В робота. Земли робота и Arduino **не соединять** — в этом весь смысл
развязки.

**Какая именно линия:** `ToolDO1` — инструментальный выход **на фланце**, не
клеммник контроллера. Найдено перебором 2026-09-03, `tools/run_find_es01.sh`.

Отсюда следствие для сборки: врезаться надо в разъём фланца, куда воткнут
ES01, то есть нужен разветвитель на этот авиаразъём. Провода от него идут
вдоль плеча к Arduino — закрепить так, чтобы не натягивались на крайних позах
кисти. Тот же разветвитель нужен под INA219, если дойдёт до токовой
модальности; имеет смысл делать его сразу на оба отвода.

**Проверь мультиметром до сборки**, робот выдаёт 24 В на ToolDO1 (sourcing) или
замыкает на землю (sinking). От этого зависит, куда включать светодиод.

## Сборка

```bash
arduino-cli compile --fqbn arduino:avr:nano firmware/suction_sensor
arduino-cli upload  --fqbn arduino:avr:nano -p /dev/ttyUSB0 firmware/suction_sensor
```

## Первая проверка (датчик на столе, без робота)

```bash
python3 -m serial.tools.miniterm /dev/ttyUSB0 500000
```
Должны идти строки `D <seq> <micros> <adc> 0`. Зажми пальцем сопло и подсоси —
`adc` уедет в минус. Ожидаемая частота 100+ Гц; если меньше, проверь, что
`Wire.setClock(400000)` применился и опрос Sco не упирается в таймаут.

Потом ткни D2 на землю проводком — должна выскочить строка `E <micros>
suction_on`. Это проверка канала t=0 без робота.

## Калибровка шкалы

`adc / 64 = Па` относительно заводского нуля. Команда `T` при открытой чашке
снимает атмосферный офсет. Один раз сверь со стрелочным вакуумметром и запиши
в статью — заводскую калибровку на слово не принимай.

Учти паспорт ES01: разрежение 55 кПа. Значения глубже примерно −55 кПа —
признак того, что шкала врёт, а не что присоска превзошла себя.

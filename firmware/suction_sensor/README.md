# Прошивка вакуумного моста

## Распиновка (Arduino Nano)

| Пин | Куда |
|---|---|
| A4 (SDA) | XGZP6847D SDA (+ подтяжка 4.7 кОм на VCC) |
| A5 (SCL) | XGZP6847D SCL (+ подтяжка 4.7 кОм на VCC) |
| 5V, GND | питание датчика |
| D5 | затвор IRLZ44N → насос 12 В |
| D6 | затвор IRLZ44N → клапан 12 В |

На каждый MOSFET: 10 кОм затвор→GND, обратный диод 1N4007 параллельно нагрузке
(катод к +12 В). Земли Arduino и БП 12 В **соединить**.

## Сборка

```bash
arduino-cli compile --fqbn arduino:avr:nano firmware/suction_sensor
arduino-cli upload  --fqbn arduino:avr:nano -p /dev/ttyUSB0 firmware/suction_sensor
```

## Первая проверка (до подключения насоса)

```bash
python3 -m serial.tools.miniterm /dev/ttyUSB0 500000
```
Должны идти строки `D <seq> <micros> <adc> 0 0`. Дунь в трубку — `adc` уедет.
Ожидаемая частота — 100+ Гц; если меньше, проверь, что `Wire.setClock(400000)`
применился и что опрос Sco не упирается в таймаут.

## Калибровка перед экспериментами

`adc / 64 = Па` относительно заводского нуля. Тарировка (`T`) при открытой
чашке снимает атмосферный офсет. Стрелочный вакуумметр в линии нужен, чтобы
один раз проверить шкалу и написать это в статье — заводскую калибровку на
слово не принимай.

# Половина проекта, работающая без ROS и без камеры: рука Dobot, решение
# hand-eye, генерация и проверка ChArUco-доски, вся математика.
#
# Это единственный файл, нужный на машине БЕЗ стенда — Windows, macOS, ноутбук
# для обработки данных. Ставится в обычный venv:
#
#   python -m venv .venv
#   .venv/bin/pip install -r requirements-portable.txt      # Linux / macOS
#   .venv\Scripts\pip install -r requirements-portable.txt  # Windows
#
# Что НЕ поедет: съёмка кадров. Драйвер HP60C собран под Linux и работает
# через ROS 2 Jazzy, официальной сборки под Windows у ROS 2 Jazzy нет.
# Параметры калибровки при этом переносимы полностью — в data/calib/*.json
# лежат только числа.

# ================= НЕ СТАВИТЬ ЭТОТ ФАЙЛ НА МАШИНУ СО СТЕНДОМ =================
# Здесь есть opencv-python. В venv рабочей машины он затенит системный cv2
# 4.6.0, против которого собран cv_bridge, и камера отвалится. Там ставится
# requirements.txt, а cv2/numpy берутся из системного ROS 2.
# =============================================================================
